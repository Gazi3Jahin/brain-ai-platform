ABOUT THE MODEL

Understanding the AI system

BrainAI uses deep learning to identify and segment tumor regions in multi-modal brain MRI scans.

MODEL ARCHITECTURE

U-Net segmentation network

The baseline model uses an encoder-decoder architecture designed for pixel-level medical image segmentation. Skip connections help preserve spatial information between the input image and the predicted segmentation.

INPUT DATA

Multi-modal MRI

FLAIR

Fluid-sensitive MRI modality useful for highlighting abnormal tissue.

T1

Structural MRI information used as one of the model input channels.

T1ce

Contrast-enhanced T1-weighted imaging.

T2

T2-weighted information providing complementary tissue characteristics.

DATASET

BraTS 2021

The model is being developed using the Brain Tumor Segmentation (BraTS) dataset. Each subject contains multiple MRI modalities together with a reference segmentation mask.

LIMITATIONS

Important considerations

  • The current system is a research and educational prototype.
  • Model performance depends on the characteristics of the training and input data.
  • The system is not intended to provide clinical diagnosis.
  • Further validation across independent clinical datasets would be required before clinical use.
